Saved scripts

Walmart Open Orders → Reserved

Checks open Walmart order lines and adds the ordered quantity to Online Orders / Reserved (Location 5). Duplicate Walmart order lines are skipped automatically.

Recommended workflow: Run Preview first. Review every matched/unmatched order line. Only use Apply after the preview looks correct.

Saved scripts

Amazon Open Orders → Reserved

Pulls merchant-fulfilled Amazon open orders through SP-API and adds matched quantities to Online Orders / Reserved (Location 5).

Recommended workflow: Preview first, inspect matches, then Apply. Amazon order ID + order item ID prevents duplicate adds.

Saved scripts

Amazon Order History & Sales Stats

Downloads historical Amazon orders into BrooksHouse for reporting only. This does not change inventory.

Safe history sync: Existing orders are updated instead of duplicated. The default button imports the last 365 days and includes Amazon proceeds for sales totals.
