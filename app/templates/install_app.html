Android & Zebra

  1. Open this page in Chrome.
  2. Tap Install BrooksHouse.
  3. Approve the installation.
  4. Launch the BrooksHouse icon.
  5. Enable notifications inside the installed app.

iPhone & iPad

  1. Open this page in Safari.
  2. Tap the Share icon.
  3. Select Add to Home Screen.
  4. Enable Open as Web App.
  5. Open the new icon before enabling notifications.

What stays online

BrooksHouse does not save scans or inventory changes offline. That prevents duplicate or missing inventory. If the server is unreachable, the app shows a clear offline screen.
